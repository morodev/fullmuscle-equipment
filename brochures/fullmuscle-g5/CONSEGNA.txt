RIGENERAZIONE
Ambiente usato: Windows, Node.js 24 e Google Chrome installato.
Dalla radice del progetto:
  npm run brochure:build
  npm run brochure:check
Per controllare il file pubblico dopo la pubblicazione:
  node brochures/fullmuscle-g5/scripts/check-public.mjs
L'esportazione si interrompe se mancano immagini o falliscono i controlli.
